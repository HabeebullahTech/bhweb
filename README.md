# 🕌 BaytulHub

A modern and responsive website for **BaytulHub**—a platform dedicated to supporting individuals, families, and organisations through Islamic education, personal development, counselling, Hajj training, and digital services.

BaytulHub is built around the idea of transforming knowledge into meaningful action through a journey of **learning, understanding, practice, character development, responsibility, and service**.

---

## 🌟 About the Project

The BaytulHub website serves as a central platform where visitors can explore the different services and programmes offered by the organisation.

The website provides information about:

* 📖 Qur'an memorization and Islamic education
* 🎓 Structured learning programmes for children and adults
* 🔄 Muroja'ah and Qur'an revision support
* 🕋 Hajj training
* 🤝 Counselling and family support
* 💻 Digital services and technology solutions
* 🛍️ Islamic products and resources
* 💬 Testimonials and frequently asked questions

---

## ✨ Features

### 🏠 Interactive Hero Section

A visually engaging hero section with multiple slides introducing visitors to BaytulHub's services and mission.

### 📚 Islamic Academy

Information about structured learning programmes, including:

* Qur'an memorization
* Islamic Studies
* Arabic learning
* One-on-one recitation correction
* Progress tracking
* Parent updates
* Character development

### 🔄 Muroja'ah Support

The platform highlights the importance of consistent Qur'an revision through features such as:

* Daily revision goals
* Regular assessments
* App reminders
* Accountability partners
* Progress check-ins

### 👨‍👩‍👧‍👦 Programmes for Children and Adults

Interactive tabs allow visitors to explore programmes specifically designed for:

* Children
* Adult learners

### 💻 Digital Services

BaytulHub also provides digital solutions for Islamic organisations, schools, businesses, and individuals.

Services include:

* Website design and development
* Mobile applications
* School management systems
* Learning management systems
* E-commerce systems
* Booking systems
* Custom software
* UI/UX design
* Branding
* Digital strategy
* Maintenance and support

### ❓ Frequently Asked Questions

An interactive FAQ section provides answers to common questions about the Academy, Muroja'ah, counselling, and digital services.

### 💬 Testimonials

A section dedicated to sharing experiences and feedback from students and parents.

### 📱 Responsive Design

The website is designed to provide a smooth experience across different screen sizes, including desktop, tablet, and mobile devices.

## 🚀 Getting Started

To run this project locally:

### 1. Clone the repository

```bash
git clone https://github.com/your-username/baytulhub.git
```

### 2. Navigate into the project folder

```bash
cd baytulhub
```

### 3. Open the project

Open the `index.html` file in your browser.

Alternatively, if you are using **VS Code**, you can use the **Live Server** extension to run the website locally.
